# 排班系统 · Shift-plannning-system

一个可直接公网试用的排班 Web 应用：管理员工与班次类型，在周排班表上点选排班，自动检测冲突（同日多班次 / 班次时间重叠 / 周工时超限），并汇总每人每周工时与每日覆盖。

## 功能
- 员工管理：姓名、角色、每周最大工时
- 班次类型：名称、颜色、起止时间（支持跨午夜，如 00:00–08:00）
- 周排班表：员工 × 周一至周日，点格即可排/改/删班次
- 冲突检测：同日重复排班、时间重叠、周工时超限，红框高亮
- 统计：每人每周工时、每日各时段覆盖人数
- 数据持久化：服务端 `data.json`（多人共享同一份数据）

## 本地运行
```bash
npm start        # 或 node server.js
# 打开 http://localhost:3000
```
无需 `npm install`（零依赖，仅用 Node 内置模块）。

## 公开部署
- 任意支持 Node 的平台：`node server.js`（监听 `PORT` 环境变量，默认 3000）
- 本仓库已通过 WorkBuddy 发布为公开服务，可直接在线试用。

## 技术栈
纯前端（原生 HTML/CSS/JS）+ 零依赖 Node HTTP 服务，无构建步骤。
